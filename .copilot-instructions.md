# Instructions Copilot - Filament Permission Manager

## Contexte du projet
- **Framework** : Laravel avec Filament V4
- **Package** : filament-permission-manager 
- **Versions** : Filament V4, PHP 8.1+, Laravel 10+

## Signatures Filament V4 OBLIGATOIRES

### Resources
```php
// Navigation
protected static string|\BackedEnum|null $navigationIcon = 'heroicon-o-users';
protected static string|\UnitEnum|null $navigationGroup = 'Administration';

// Forms - UTILISER Schema au lieu de Form
public static function form(Schema $schema): Schema
{
    return $schema->components([...]);
}

// Tables - UTILISER les nouvelles méthodes d'actions
public static function table(Table $table): Table
{
    return $table
        ->recordActions([...])      // au lieu de ->actions()
        ->toolbarActions([...]);    // au lieu de ->bulkActions()
}
```

### Pages
```php
// UserSettings doit implémenter HasForms
class UserSettings extends Page implements HasForms
{
    use InteractsWithForms;
    
    protected string $view = 'filament.pages.user-settings';  // string, pas ?string
    
    public function editForm(Schema $schema): Schema  // Schema, pas Form
}
```

### Imports OBLIGATOIRES (directs, pas groupés)
```php
// ❌ INTERDIT V3
use Filament\Forms;
use Filament\Tables;

// ✅ OBLIGATOIRE V4  
use Filament\Forms\Components\TextInput;
use Filament\Tables\Columns\TextColumn;
use Filament\Actions\EditAction;
```

## Règles strictes
1. **TOUJOURS** utiliser `Schema` au lieu de `Form`
2. **TOUJOURS** importer les composants directement 
3. **TOUJOURS** utiliser `recordActions()` et `toolbarActions()`
4. **TOUJOURS** vérifier les signatures avec BackedEnum/UnitEnum
5. **JAMAIS** utiliser la syntaxe groupée V3

## Mots-clés de détection d'erreur V3
Si tu vois ces éléments, c'est du V3 à corriger :
- `Forms\Components\*`
- `Tables\Columns\*` 
- `->actions([...])`
- `->bulkActions([...])`
- `public static function form(Form $form)`
